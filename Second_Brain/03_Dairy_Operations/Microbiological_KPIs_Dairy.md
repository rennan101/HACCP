# 🔬 Microbiological KPIs for Dairy Products

To verify the effectiveness of the [[HTST_Pasteurisation|Pasteurisation Kill Step]] and [[Prerequisite_Programmes_PRPs|Good Manufacturing Practices (GMP)]], every production batch is tested against strict microbiological specifications.

---

## 📊 Batch Release Specification Table

| Test / Organism | Test Frequency | Target Value | Action / Reject Threshold | Operational Meaning |
| :--- | :--- | :--- | :--- | :--- |
| **Total Viable Count (TVC)** | Per Batch | $< 5,000\text{ /g}$ | $\ge 10,000\text{ /g}$ | General hygiene indicator & plant flora |
| **Presumptive Enterobacteriaceae** | Per Batch | $< 20\text{ /g}$ | $\ge 20\text{ /g}$ | Post-pasteurisation contamination marker |
| **Presumptive *Staphylococcus aureus*** | Per Batch | $< 20\text{ /g}$ | $\ge 20\text{ /g}$ | Operator hygiene / handling indicator |
| ***Salmonella spp.*** | Per Batch | **Absent in 25g** | **Present in 25g** | Zero Tolerance Critical Pathogen |
| ***Listeria monocytogenes*** | Per Batch | **Absent in 25g** | **Present in 25g** | Zero Tolerance Environmental Pathogen |
| **Presumptive *Bacillus cereus*** | Per Batch | $< 100\text{ /g}$ | $> 500\text{ /g}$ | Spore-former / Chilling delay marker |

---

## 🚨 Non-Conformance Protocol

If any batch fails to meet the Target Value or hits the Reject Threshold:
1. **Immediate Product Quarantine**: Tagged [[HACCP_Team_and_Quarantine_ON_HOLD|ON-HOLD]].
2. **Quality Investigation**: Technical team investigates the thermal thermographs and CIP records.
3. **Environmental Swabbing**: Line undergoes deep sanitation and swab verification before restart.
